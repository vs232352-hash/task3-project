# Task 3 – Advanced Features Implementation

**Internship:** Web Development (PHP & MySQL)
**Company:** ApexPlanet Software Pvt. Ltd.
**Timeline:** 10 Days

## Objective
- Enhance the CRUD application with Search and Pagination features.
- Improve the User Interface using Bootstrap 5.

## New Features Added (over Task 2)

### 1. Search Functionality
- Search bar to search posts by title or content.
- Shows count of results found.
- Clear button to reset search.

### 2. Pagination
- 5 posts per page.
- Previous, page numbers, Next buttons.
- Works together with search.

### 3. UI Improvements
- Bootstrap 5 responsive design.
- Professional navbar with icons.
- Card-based post layout with hover effect.
- Styled login and register forms.

## How to Run
1. Make sure blog database exists (from Task 2).
2. Copy folder to C:\xampp\htdocs\task3-project
3. Start Apache and MySQL in XAMPP.
4. Visit http://localhost/task3-project/login.php

## Deliverables
- Updated application with Search and Pagination.
- Improved professional UI with Bootstrap 5.
